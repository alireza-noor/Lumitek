# Lumitek v0.3.1 Backend

این نسخه بر پایه مستقیم v0.3.0 ساخته شده است.

## اضافه شد
- Profile API
- Game score API
- Leaderboard API
- Daily reward
- Store catalog
- Atomic store purchase
- Notifications listing/read
- D1 tables: daily_rewards, store_items, purchases
- Indexes و starter store catalog
